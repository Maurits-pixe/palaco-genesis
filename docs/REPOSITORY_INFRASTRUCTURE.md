# Repository Infrastructure

## Top-level structure
- `content/` — PALACO knowledge assets, architecture notes, and domain content.
- `languages/` — source code grouped per programming language (e.g. `languages/rust/`, `languages/python/`).
- `docs/` — contributor-facing documentation about repository operations and standards.
- `.github/workflows/` — CI/CD automation workflows.

## Structuring rules
- Nieuwe kennis- en domeininhoud gaat onder `content/`.
- Nieuwe code gaat onder `languages/<language>/`.
- Repository-brede richtlijnen en handleidingen blijven onder `docs/`.
