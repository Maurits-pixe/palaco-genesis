# RIO Mobile

Mobile-first concept preview for the RIO app surface. Start the [local RIO message service](../../services/rio-messaging/README.md), then open http://127.0.0.1:4317/rio-mobile/. Set a display name in Profile and share a local conversation link to sync messages and timestamps between browser tabs. Names are not verified; messages are held in memory only. The hosted preview is visual-only.
