# RIO Web

Responsive concept preview for the RIO conversation surface. Start the [local RIO message service](../../services/rio-messaging/README.md), then open http://127.0.0.1:4317/rio-web/. Set a display name, share a local conversation link, and see names and message times sync between browser tabs. Names are not verified; messages are held in memory only. The hosted preview is visual-only.
