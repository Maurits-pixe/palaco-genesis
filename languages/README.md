# PALACO Language Hub

Deze map organiseert PALACO code per programmeertaal.

## Structuur
- `rust/` — Rust crates, tooling en standaarden
- `python/` — Python services/scripts en standaarden
- `typescript/` — TypeScript apps/libs en standaarden

## Richtlijn
