# RIO

RIO is the human interaction layer of PALACO. It does not inherit constitutional authority automatically.

## Central loop
Request → Identity → Context → Memory → Knowledge → Evidence → Agents → TRIAS → Answer or Action → Provenance → Trace

## Surface rule
RIO may appear in web, mobile, Citadel, ELIXER, and PALACO.NL surfaces, but every surface must reuse the same constitutional core.
