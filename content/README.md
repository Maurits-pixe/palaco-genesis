# PALACO Content Hub

Deze map is de verzamelplek voor alle niet-executable PALACO content.

## Structuur
- `specs/` — formele specificaties (PRI's, contracts, RFC's)
- `docs/` — gebruikers- en developer documentatie
- `research/` — analyses, verkenningen, benchmark-notes
- `playbooks/` — operationele runbooks en procedures

## Inname-regels
- Elke bijdrage krijgt een duidelijke titel en datum.
- Plaats nieuwe inhoud altijd in de juiste submap.
- Verwijs vanuit documentatie naar bronbestanden in deze map.
